# TextDeck 功能说明

**把事先准备好的文字，逐字符输入到任何 Windows 窗口。**

TextDeck 是一套 Windows 文字输入工具：你把要输入的内容提前编辑好，点一下按钮或按一个快捷键，它就把文字一个字符一个字符地"敲"进当前窗口——不是复制粘贴，不经过剪贴板。

## 1. 它解决什么问题

日常里有很多"要把同一段文字敲进某个窗口"的场景，但那个窗口可能不支持粘贴，或者粘贴会带上不需要的格式：

- 某些远程桌面、虚拟机、游戏、工业软件的输入框**禁用了粘贴**；
- 需要向**命令行终端、BIOS、虚拟机控制台**等逐字输入配置命令；
- 想把一段固定文案（问候语、测试文本、申报内容）反复敲进不同地方；
- 需要一个"可控的打字员"：能随时暂停、停止，且敲的内容与你准备的完全一致。

这些场景下，剪贴板（Ctrl+V）不管用，手工敲又费时费力。TextDeck 就是为这类需求准备的。

## 2. 三种输入方式，按需选择

TextDeck 主程序内置三种互相独立的输入方式。在界面上明确选定一种，**程序不会自动切换，也不会悄悄换方式**：

| 输入方式 | 是什么 | 需要什么 | 能输入什么 |
|---|---|---|---|
| **软件输入模式**（推荐先用这个） | Windows 自带的 SendInput 键盘事件 | 什么都不用装，免管理员 | **任意文字**，包括中文、日文、emoji、特殊符号 |
| **ESP32 USB HID 模式** | 一块烧了固件的 ESP32-S3 开发板变成"真 USB 键盘"，程序通过 USB 线指挥它打字 | 一块 ESP32-S3 开发板（约几十元）+ 一根 USB 数据线 | 英文、数字、常见英文标点、空格、Tab、换行 |
| **TextDeck HID 模式** | 内核级虚拟键盘驱动 | 需要自行编译并签名驱动（**本包不含成品驱动**） | 英文、数字、常见英文标点、换行、Tab |

**没有"最好的一种"，只有"适合你的那一种"：**

- 只想在普通 Windows 程序里输入文字（含中文）→ 用**软件输入模式**，零成本开始；
- 目标窗口不接受软件模拟的按键（某些游戏、远程控制、安全软件场景）→ 用 **ESP32 模式**，它对系统而言就是一块真的 USB 键盘；
- 需要内核级虚拟键盘且有能力自行构建签名驱动 → 用 **TextDeck HID 模式**。

## 3. 主要功能

### 3.1 文本输入

- 在主程序的编辑框里准备一段文字（可反复编辑、清空、重新粘贴进来）；
- 点"开始"按钮（有 3 秒倒计时，方便你把光标点进目标窗口），或直接按**开始快捷键**；
- 文字会逐字符输入到**当时获得焦点的窗口**；
- 输入结束或中途停止后，状态栏给出统计：本次实际输入多少字符、跳过多少字符。

### 3.2 停止控制（随时可停）

三种方式可以随时中断输入，按下后设备立即停止，不再产生新字符：

1. **专用停止键**：单个按键，默认是 `Pause`；笔记本一般没有 Pause 键，可在设置里改成 `F10` 等任意单键。**推荐把它设成你顺手的单键**——它不带 Ctrl/Alt/Shift 修饰键，停止时不会吞掉正在输入的字符；
2. **停止组合键**：`Ctrl+Alt+Shift+F10`（备用通道）；
3. **界面上的"停止"按钮** / 托盘菜单里的"停止输入"。

其他安全保护：

- 倒计时阶段按停止 = 取消本次任务，一个字符都不会发；
- **输入过程中切换窗口焦点会自动停止**，防止文字串进别的窗口；
- 连续多次按停止不会出错，停止后立刻可以开始下一段输入；
- 停止的实际延迟在几十毫秒量级（实测中位约 30 ms，远低于 200 ms）。

### 3.3 按键配置

- 「快捷键设置」里可以分别改**开始键**、**停止组合键**、**专用停止键**；
- 三个键独立注册：某个键被其他软件占用时，只有那一项会显示"注册失败"并保留原设置，其余功能不受影响；
- 组合键被占用时会弹出明确提示（含错误码），不会静默失效；
- 有"恢复默认"按钮一键还原；
- 配置保存在本地配置文件里，重启程序后仍然有效。

### 3.4 输入映射工具（TextDeck Mapping）

包里另附一个命令行工具，可以把**键盘、鼠标、游戏手柄、串口、UDP 消息**等输入事件映射成按键动作或按键脚本——例如"按手柄 A 键 = 敲空格"、"收到 UDP 消息 = 执行一串组合键"。

- 配置写在 JSON 文件里，`map_app.exe example` 可直接生成一份能跑的示例；
- 自带安全的"录制（record）"模式，正式生效前可以先看清会敲什么；
- 详细用法见 `01-TextDeck-Mapping/README.md` 与《使用说明.md》第 5 节。

### 3.5 ESP32-S3 设备如何配合

```text
┌──────────────────────┐        USB 一根线        ┌──────────────────┐
│  Windows 上的主程序   │ ──── 串口（发文字/命令）──→ │  ESP32-S3 开发板  │
│  VirtualHIDTyper.exe │ ←─── 串口（状态/计数）──── │  （烧好固件）     │
└──────────────────────┘                          │  = 一只 USB 键盘  │
        │                                         └────────┬─────────┘
        │ 状态栏显示进度                                     │ HID 按键
        ▼                                                  ▼
   你正在看的窗口  ←─────────── 系统当作真实键盘输入 ──────────┘
```

- 开发板通过**一根 USB 数据线**同时完成两件事：收文字（USB 串口）+ 打字（USB HID 键盘）；
- 对 Windows 来说，它就是一只普通键盘——所以那些不接受软件模拟按键的窗口也能用；
- 板上的 **BOOT 键**按一下，可以本地触发一次输入；
- 主程序会在连接时核对固件版本（需 v1.2 / 0x0102 及以上），版本不符会明确提示；
- 烧录方法、所需开发板型号见《安装说明.md》与《使用说明.md》第 4 节。

## 4. 典型使用场景

| 场景 | 用哪种方式 |
|---|---|
| 向禁用粘贴的输入框填入长文本 | 软件输入模式 |
| 在虚拟机 / 远程桌面 / 终端里逐字输入命令 | 软件输入模式或 ESP32 模式 |
| 目标是游戏、工控软件、安全沙箱等不认模拟按键的窗口 | ESP32 模式 |
| 需要输入中文、emoji | 只能用软件输入模式 |
| 反复向多个窗口输入同一段固定文案 | 任意方式（文字可反复使用） |
| 把手柄/网络消息变成按键动作 | TextDeck Mapping |

## 5. 使用限制与注意事项

这些是各输入方式的**真实边界**，请在使用前了解：

### 5.1 通用

- 文字输入到**当前获得焦点的窗口**——开始前请先把光标点进目标输入框；
- 输入期间切换窗口会自动停止（保护机制），请尽量不要在打字时切窗口；
- 无法向以管理员权限运行的窗口输入（Windows UIPI 限制）。程序会直接报错停止，**不会尝试绕过系统安全机制**。

### 5.2 ESP32 模式（真实 USB 键盘的固有特性）

- **只能表达 US 键盘布局能敲出来的字符**：英文字母、数字、常见英文标点、空格、Tab、换行。**中文、emoji 不支持**，写入设备时就会被拒绝并明确提示，不会静默替换；
- 长度上限 **10,240 字节**，超出或空白文本都会被拒绝；
- **CapsLock 开着时，所有字母的大小写会翻转**（和真键盘一样：CapsLock 下按 Shift+a 会得到 a）。输入英文前请确认 CapsLock 状态，程序不会替你改它；
- 中文输入法处于活动状态时可能改写按键（例如空格变"确认候选词"、标点变全角）。用 ESP32 输入前请切到英文输入法；
- 换行会统一成 `\n`（`\r\n` 和单独的 `\r` 都会转换），这是设计行为不是丢字。

### 5.3 软件输入模式

- 机制上等于"一个很快的人在按键"，不产生任何新硬件；
- 无法输入到管理员权限窗口（见上）。

### 5.4 TextDeck HID 模式

- **本包不含任何已编译的驱动**（没有 `.sys`/`.cat`，也没有证书或私钥）。`04-Driver-Source` 里只是**源码**，需要的人要自己用 WDK 编译并签名后才能安装；
- 当前驱动没有生产签名，普通 Windows 无法直接安装；详见《安装说明.md》第 8 节。
