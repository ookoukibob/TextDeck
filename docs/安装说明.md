# TextDeck 安装说明

本说明告诉您：下载后怎么装、包里每个文件是干什么的、怎么把 ESP32-S3 接上、第一次怎么用起来。
**全程不需要读源码，也不需要管理员权限**（除非您要自行构建内核驱动）。

想先了解 TextDeck 能做什么，请看 **《功能说明.md》**；具体操作细节请看 **《使用说明.md》**。

---

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| 磁盘空间 | 约 20 MB |
| 运行权限 | 普通用户即可（**不需要管理员**） |
| 联网 | 不需要 |
| 可选硬件 | ESP32-S3 开发板（N16R8 类：16 MB Flash + 8 MB PSRAM）+ USB 数据线 |

---

## 2. 安装步骤（其实就是"解压"）

TextDeck 是**绿色便携软件**，没有安装程序，解压即用：

1. 下载 `TextDeck-Portable-v1.0.0.zip`；
2. （可选但建议）按第 7 节校验文件完整性；
3. 右键 ZIP →"全部解压缩"，解压到任意目录，例如 `D:\TextDeck\`；
   - 解压后只有一个顶层文件夹 `TextDeck-Portable`；
   - 路径里**尽量不要**包含特殊符号过长的中文目录名（一般无影响，出问题时换成纯英文路径再试）；
4. 进入 `TextDeck-Portable\02-TextDeck-Main\`，**双击 `VirtualHIDTyper.exe`** 即可运行；
5. （可选）右键 `VirtualHIDTyper.exe` → 发送到 → 桌面快捷方式。

**不需要安装、不需要注册、不写注册表、不装服务、不弹 UAC。**
卸载 = 直接删除整个文件夹（另见第 9 节"配置文件在哪"）。

### 3.1 运行必需 vs 可选

| 您想做什么 | 需要保留的文件 | 可以删掉的 |
|---|---|---|
| 只用软件输入模式打字 | `02-TextDeck-Main\VirtualHIDTyper.exe` + 三个根目录文档（可选） | 其余全部 |
| 用 ESP32-S3 打字 | 上一行 + `03-ESP32-Firmware\` | `01-`、`04-` |
| 用输入映射工具 | `01-TextDeck-Mapping\` | 其余不影响 |
| 想自己编译驱动 | `04-Driver-Source\`（另需 WDK） | — |

**日常用户最小集就是 `02-TextDeck-Main\VirtualHIDTyper.exe` 一个文件**（加上您自己准备的文字内容）。其余目录按需取用。

### 3.2 关于 `source\` 目录

每个工具下的 `source\` 保存了可重新编译的完整源码与构建脚本，供想查看或修改的人使用。
**不打算改代码的话可以无视，也可以删掉**，不影响程序运行。

### 3.3 关于 `04-Driver-Source`（重要）

> **这里没有任何已编译的驱动。** 没有 `.sys`、没有 `.cat`、没有证书、没有私钥，也没有现成的安装包。
> 它只是源码——需要"TextDeck HID 模式"的人必须自己用 WDK 编译并**自行签名**后才能安装。
> 当前驱动**没有生产签名**，普通 Windows 无法直接安装它。
> 只想输入文字？请直接用软件输入模式，那是完全免驱动的。详见第 8 节。

## 4. 如何连接 ESP32-S3

只用软件输入模式可以完全跳过本节。

### 4.1 准备

- 一块 **ESP32-S3** 开发板（建议 N16R8：16 MB Flash + 8 MB PSRAM）；
- 一根**能传数据**的 USB 线（很多线只能充电）；
- Arduino IDE 2.x，并在开发板管理器安装 **esp32 by Espressif** 核心（3.x）。

### 4.2 烧录固件（一次性）

1. Arduino IDE → 文件 → 打开 → 选择本包 `03-ESP32-Firmware\firmware\esp32_hid_text_device\esp32_hid_text_device.ino`；
2. 开发板选 **ESP32S3 Dev Module**；
3. 工具菜单逐项设置（**必须对上，否则编出来的是另一个设备**）：

   | 菜单项 | 必须设置为 |
   |---|---|
   | Flash Size | **16MB** |
   | PSRAM | **OPI PSRAM** |
   | USB Mode | **USB-OTG (TinyUSB)** |
   | USB CDC On Boot | **Disabled** |

4. 选择正确端口 → 验证 → 上传。

**烧录三条注意事项**：
- 不要使用"全片擦除"（Erase All Flash）来解决普通烧录失败——它会连板内已保存的文字一起清掉；
- 不要改分区表、不要动 eFuse；
- 烧录失败先检查：串口是否被别的程序占用、板型是否选对、端口是否选对。
完整说明见 `03-ESP32-Firmware\firmware\README-esp32.md` 与《使用说明.md》第 4 节。

### 4.3 日常连接

1. USB 线连接开发板的**原生 USB 口**（GPIO19 = D-，GPIO20 = D+）与电脑；
2. Windows 会自动认出两个设备（都用系统自带驱动，无需安装）：
   - **HID Keyboard Device** —— 真正打字用
   - **USB 串行设备 (COMx)** —— 程序下发文字用
3. 打开主程序，把输入模式切到 **「ESP32 USB HID 模式」**，在串口下拉框选中那个 COMx（程序通常会自动选中，选择会被记住）。

## 5. 首次使用基本步骤（推荐路径）

1. 双击 `02-TextDeck-Main\VirtualHIDTyper.exe`；
2. 确认界面上显示 **「软件输入模式」**（默认就是它，无需驱动、支持中文）；
3. 在编辑框里输入或粘贴一段测试文字，如 `Hello TextDeck 123`；
4. 打开记事本，**点一下记事本的输入区**让光标在里面；
5. 回到主程序点"开始"（3 秒倒计时内再点回记事本），或先点进记事本再按开始快捷键 `Ctrl+Alt+Shift+F9`；
6. 看到文字被逐字符敲进记事本 —— 安装完成；
7. 试着在输入过程中按 **停止** 按钮，确认随时能停。

之后的常规用法：

- **开始**：点"开始"按钮，或按 `Ctrl+Alt+Shift+F9`；
- **停止**：按专用停止键（默认 `Pause`，笔记本请在「快捷键设置」里改成 `F10`）、`Ctrl+Alt+Shift+F10`、或点"停止"按钮；
- **改快捷键**：主界面 →「快捷键设置」，三行分别对应开始 / 停止组合键 / 专用停止键，支持"恢复默认"；
- **换输入方式**：主界面单选框切换三种模式（ESP32 模式需先接好设备）。

## 6. 停止与安全保护（用之前知道这几条）

- 输入期间**切换窗口会自动停止**，防止文字串进别的窗口——请尽量打字时别切窗口；
- 倒计时阶段按停止 = 本次任务取消，一个字符都不发；
- 无法向管理员权限窗口输入（Windows UIPI 限制），程序会直接报错停止，不会绕过；
- ESP32 模式下 **CapsLock 开着会让所有字母大小写翻转**；中文输入法可能改写按键（空格变确认、标点变全角）——输入英文前请关掉 CapsLock、切到英文输入法；
- ESP32 模式只支持英文/数字/常见英文标点/空格/Tab/换行，**长度上限 10,240 字节**，中文会被明确拒绝（详见《功能说明.md》第 5 节）。

## 7. 校验下载的文件

如果 SHA256SUMS.txt 或您下载的 ZIP 有单独提供的 `.sha256` 文件，先核对 ZIP 本身：

```powershell
Get-FileHash .\TextDeck-Portable-v1.0.0.zip -Algorithm SHA256
```

解压后核对包内每个文件（推荐）：

```powershell
cd TextDeck-Portable
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify-package.ps1
```

输出"结果：全部一致。"即通过。注意清单是 UTF-8 编码，**不要**用 `Get-Content` 默认编码直接读 `SHA256SUMS.txt`（中文文件名会乱码）——请用上面的脚本。

## 8. 关于内核驱动（多数用户请直接跳过）

只有想用「TextDeck HID 模式」的人才需要关心本节。

- `04-Driver-Source` 是驱动**源码**，不是安装包；
- 自行构建需要 Visual Studio 2022 Build Tools + Windows SDK + **Windows Driver Kit (WDK)**；
- 构建出来的驱动**没有生产签名**，只能在开启测试签名的系统上加载（或自行走正式签名流程）；
- **不要**为了这个驱动去关闭 Secure Boot、修改驱动签名策略或降低系统安全设置；
- 完整步骤、签名要求与安全边界见 `04-Driver-Source\README-驱动源码说明.md` 与 `docs\SIGNING.md`。

不需要内核级虚拟键盘的话，软件输入模式和 ESP32 模式都不需要任何驱动。

## 9. 常见问题

**Q：杀毒软件 / SmartScreen 报警？**
A：程序是自己构建的便携 exe，没有商业代码签名证书，偶发误报属正常。可以查看源码（包内 `source\`）自行构建，或添加信任后使用。

**Q：双击没反应 / 闪退？**
A：把整个 `TextDeck-Portable` 目录解压到纯英文短路径（如 `D:\TextDeck\`）再试；确认是 64 位 Windows 10/11。

**Q：按了快捷键没反应？**
A：先看状态栏——快捷键是否显示"注册失败"（被其他软件占用）。可到「快捷键设置」换一组键。另外快捷键是"全局"的，但开始前光标必须已经在目标输入框里。

**Q：软件输入模式打到一半停了 / 报"焦点离开目标窗口"？**
A：这是保护机制：输入期间切换了窗口会自动停止，防止文字进错窗口。重新点进目标输入框再开始即可。

**Q：ESP32 模式下输入的英文大小写反了？**
A：CapsLock 开着。关掉 CapsLock 再输入（程序不会替您改键盘状态）。

**Q：ESP32 模式下空格没打出来 / 标点变成全角？**
A：中文输入法在改写按键。切换到英文输入法（如微软拼音的"英"模式）再试。

**Q：ESP32 模式说"固件版本过低"？**
A：板上固件不是本包配套版本。按第 4.2 节重新烧录 `03-ESP32-Firmware` 里的固件。

**Q：文本太长被拒绝？**
A：ESP32 模式上限 10,240 字节。请分段输入，或改用软件输入模式（无此限制）。

**Q：配置改乱了怎么恢复？**
A：「快捷键设置」里有"恢复默认"按钮。配置文件保存在 `%APPDATA%\VirtualHIDTyper\settings.ini`，删掉它再启动即恢复出厂默认。

**Q：怎么完全卸载？**
A：关闭程序（含托盘图标），删除 `TextDeck-Portable` 文件夹；如想连配置一起清掉，再删除 `%APPDATA%\VirtualHIDTyper\`。

**Q：能商用吗？**
A：本包使用 PolyForm Noncommercial License 1.0.0——非商业用途免费，商业使用需另行授权，见 `LICENSE`。
